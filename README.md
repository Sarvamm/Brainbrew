[BrainBrew]("https://brain-brew.streamlit.app/") is a Streamlit application that uses Large Language Models to help users learn.
It takes user-provided *topics*  to generate **detailed notes**, and **interactive multiple-choice quizzes**.
The app manages user data and progress using *session state* across different features.
